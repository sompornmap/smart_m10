# smart_M10

## v4 Multi-Year / Multi-Month
- เปลี่ยนปีและเดือนได้จริง โดยข้อมูลแต่ละเดือนแยกจากกัน
- นำเข้า CSV ได้หลายไฟล์พร้อมกัน (`multiple`)
- แยกข้อมูลเข้ารายเดือนอัตโนมัติจาก `REG_DATE`
- รองรับข้อมูลหลายเดือนใน CSV เดียว
- Export เดือนปัจจุบัน หรือเลือกหลายเดือนรวมเป็น Excel workbook เดียว
- ย้ายข้อมูล localStorage `m10_v3` เดิมเข้าสู่ `m10_v4` อัตโนมัติ
- แสดงจำนวนข้อมูลของเดือนปัจจุบันใต้ตัวเลือกปี/เดือน
